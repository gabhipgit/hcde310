## Resource 1: Last.fm 

**What it provides** (1–2 sentences):
Last.fm provides people the chance to build music related projects. It allows people to tinker with/access data from albums, artists, top charts, and their own user data. It also has methods for authentication, library, and tags. 

**Docs link:** https://www.last.fm/api/intro

**Access:** API key needed? Rate limits? Cost? (write "none" if none) 
An API key is needed, and a User-Agent header is needed for requests. 
There is a rate limit, but it's not specifically specified.  
Cost: None (For using the API)

## Resource 2: Merriam-Webster (Collegiate Thesaurus)

**What it provides** (1–2 sentences):
Merriam-Webster's API provides dictonary and thesaurus resources (for example, definititions, pronounciations, and synonyms) for developing projects. It provides this content for other speacilized dictionaries as well (such as medical, and Spanish vocab).

**Docs link:** https://www.dictionaryapi.com/products/json

**Access:** API key needed? Rate limits? Cost? (write "none" if none)
API key is needed for this API.
Rate limit cannot exceed 1000 queries a day (per API key). No more than 2 reference APIs.
Cost: None 

**Sample response** (trim it to a few fields; paste the URL you called too):

**Who could this data help, and with what?** (2–3 ideas)

2. People learning English studying the variants of a word (tired vs tiredness).

**One risk** (missing data, bias, privacy, or reliability):
Although this API is known for defining words and providing synonyms, it does not include every word in the English (or Spanish) language. More modern words or words that have taken on new meanings would be missing data in this set.
